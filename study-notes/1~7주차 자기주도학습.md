# 1~7주차 자기주도학습

## 자기주도학습 내역

| 구분 | 내용 |
|------|------|
| 학습 기간 | 1~7주차 |
| 학습 목적 | 중간고사 대비 |
| 학습 방법 | 강의자료 정리 및 AI 실습 |
| 주요 주제 | 생성형 AI, LLM, ChatGPT, Claude, 소프트웨어공학 |
| 결과물 | 강의 요약본, 자기주도학습 보고서 |

## 학습 개요

인공지능캡스톤디자인 수업의 중간고사를 준비하기 위해 강의 자료를 정리하고 주요 개념을 복습하였다.

특히 생성형 AI, 거대언어모델(LLM), ChatGPT, Claude AI, 소프트웨어 공학 기초 개념을 중심으로 학습하였으며, 단순 암기가 아닌 실제 활용 사례와 기능을 이해하는 데 집중하였다.

---

## 학습 내용

### 1. 인공지능과 생성형 AI

학습 자료를 통해 생성형 AI와 거대언어모델(LLM)의 개념을 학습하였다.

주요 학습 내용

* 생성형 AI의 정의와 특징
* LLM(Large Language Model)의 역할
* ChatGPT, Gemini, Claude, DeepSeek 등 주요 AI 서비스 비교
* 자연어 처리(NLP)와 생성형 AI의 관계
* AI 활용 분야 및 산업 적용 사례

학습 결과

* 생성형 AI는 기존 데이터를 기반으로 새로운 콘텐츠를 생성하는 기술임을 이해하였다.
* LLM은 자연어를 이해하고 생성하는 모델이라는 점을 학습하였다.

---

### 2. 프롬프트 엔지니어링

효율적인 AI 활용을 위한 질문 설계 방법을 학습하였다.

주요 학습 내용

* 프롬프트 엔지니어링 개념
* 역할(Role) 부여 기법
* 단계별 질문 작성 방법
* 구체적인 조건 제시 방법
* 결과 개선을 위한 피드백 활용

학습 결과

* 질문 방식에 따라 AI의 응답 품질이 크게 달라질 수 있음을 확인하였다.
* 단계별 질문이 더 정확한 결과를 생성한다는 점을 이해하였다.

실습 예시

```text
너는 정보보안 전문가이다.
웹 보안 취약점 TOP 10을 설명하고,
각 취약점의 대응 방법을 제시하라.
```

---

### 3. ChatGPT 및 Claude 활용

생성형 AI 도구의 기능과 활용 방법을 학습하였다.

주요 학습 내용

* ChatGPT 앱 설치 및 사용
* 맞춤형 GPT 생성
* 프로젝트 기능 활용
* Claude AI 특징
* Claude Artifacts 기능
* Claude 모델(Opus, Sonnet, Haiku) 비교

학습 결과

* ChatGPT 프로젝트 기능을 통해 장기적인 작업을 체계적으로 관리할 수 있음을 이해하였다.
* Claude는 긴 문서 처리와 심층 추론 기능에 강점을 가진다는 점을 학습하였다.
* 목적에 따라 적절한 모델을 선택하는 것이 중요함을 확인하였다.

---

### 4. 소프트웨어 공학 기초

소프트웨어 공학의 기본 개념과 개발 프로세스를 학습하였다.

주요 학습 내용

* 소프트웨어와 프로그램의 차이
* 소프트웨어 개발의 특징
* 소프트웨어 실패 곡선
* 개발 생명주기(SDLC)
* 소프트웨어 공학의 필요성

학습 결과

* 소프트웨어는 단순한 프로그램이 아니라 문서, 설계, 테스트 결과 등을 포함하는 포괄적인 개념임을 이해하였다.
* 체계적인 개발 프로세스의 중요성을 학습하였다.

## 자기주도학습 활동

수업 자료를 정리하면서 GitHub 저장소에 강의별 요약본을 작성하였다.

학습 과정

1. 강의 PDF 검토
2. 핵심 개념 정리
3. 중요 내용 요약
4. AI 도구 실습
5. GitHub 문서화

이를 통해 단순 수업 수강이 아닌 스스로 내용을 재정리하고 복습하는 학습을 수행하였다.

---

## 학습 소감

이번 자기주도학습을 통해 생성형 AI와 소프트웨어 공학의 핵심 개념을 체계적으로 정리할 수 있었다.

특히 ChatGPT와 Claude를 직접 활용해 보면서 생성형 AI를 단순한 대화 도구가 아닌 학습과 프로젝트 수행을 지원하는 생산성 도구로 활용할 수 있음을 확인하였다.

향후에는 정보보안 분야와 생성형 AI를 결합한 프로젝트를 진행하며 실무 역량을 강화하고자 한다.
