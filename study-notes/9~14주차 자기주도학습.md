# 9~14주차 자기주도학습 

## 자기주도학습 내역

| 구분 | 내용 |
|------|------|
| 학습 기간 | 9~14주차 |
| 학습 목적 | 기말고사 대비 및 캡스톤디자인 프로젝트 수행 |
| 학습 방법 | 강의자료 정리, 개념 복습, 프로젝트 개발 및 문서화 |
| 주요 주제 | 소프트웨어 개발 프로세스, 프로토타입 모델, AI Agent, MCP, Claude Connector |
| 프로젝트 | 디지털 약자를 위한 음성 및 제스처 기반 배리어프리 키오스크 개발 |
| 결과물 | 강의 요약본, 자기주도학습 보고서, 프로젝트 산출물 |

## 학습 개요

9주차부터 14주차까지 진행된 수업 내용을 복습하고 기말고사를 준비하기 위해 자기주도학습을 수행하였다.

후반부 수업에서는 소프트웨어 개발 프로세스, 프로토타입 모델, AI Agent, MCP(Model Context Protocol), Claude Connector 등의 내용을 학습하였다. 또한 캡스톤디자인 졸업작품 개발이 본격적으로 진행되어 프로젝트 개발 활동에도 많은 시간을 투자하였다.

---

## 학습 내용

### 1. 소프트웨어 개발 프로세스

주요 학습 내용

* 소프트웨어 개발 생명주기(SDLC)
* 폭포수 모델
* V 모델
* 프로토타입 모델
* 통합 프로세스 모델

학습 결과

* 소프트웨어 개발은 요구사항 분석부터 유지보수까지 체계적인 절차를 통해 진행된다는 점을 이해하였다.
* 다양한 개발 모델의 특징과 장단점을 학습하였다.

---

### 2. 프로토타입 개발 모델

주요 학습 내용

* 프로토타입의 개념
* 시제품 개발 과정
* 사용자 요구사항 분석
* 반복적 개선 방식

학습 결과

* 초기 단계에서 프로토타입을 제작하는 이유를 이해하였다.
* 사용자 피드백의 중요성을 학습하였다.

---

### 3. AI Agent와 MCP

주요 학습 내용

* AI Agent 개념
* MCP(Model Context Protocol)
* 외부 서비스 연동 구조
* AI 기반 자동화 기술

학습 결과

* AI Agent가 단순 질의응답을 넘어 다양한 도구와 연동될 수 있음을 학습하였다.
* MCP가 AI와 외부 서비스를 연결하는 표준 프로토콜임을 이해하였다.

---

### 4. Claude Connector

주요 학습 내용

* Gmail 연동
* Google Drive 연동
* Google Calendar 연동
* Notion 연동
* 업무 자동화 사례

학습 결과

* 생성형 AI의 활용 범위가 확대되고 있음을 확인하였다.
* 다양한 서비스를 연계하여 생산성을 향상시킬 수 있음을 학습하였다.

---

## 캡스톤디자인 프로젝트 활동

### 프로젝트 주제

디지털 약자를 위한 음성 및 제스처 기반 배리어프리 키오스크

### 프로젝트 목표

고령자와 디지털 취약 계층이 보다 쉽고 편리하게 키오스크를 사용할 수 있도록 음성 및 제스처 기반 인터페이스를 제공하는 시스템을 개발하는 것이다.

### 수행 내용

* 팀원들과 기능 요구사항 정리
* 키오스크 UI 구성 논의
* 음성 인식 기술 조사
* 제스처 인식 기술 조사
* 발표 자료 제작
* 개발 일정 관리
* 프로젝트 문서 작성

### 프로젝트 진행 과정에서 느낀 점

실제 프로젝트를 수행하면서 사용자 요구사항을 반영하는 과정의 중요성을 체감할 수 있었다. 또한 팀 프로젝트에서는 기능 구현뿐 아니라 일정 관리와 의사소통 역시 중요하다는 점을 경험할 수 있었다.

## 자기주도학습 활동

기말고사를 대비하여 강의 자료를 반복적으로 검토하고 핵심 개념을 요약 정리하였다.

학습 과정

1. 강의 PDF 정리
2. 중요 개념 요약
3. 기말고사 범위 복습
4. 프로젝트 관련 기술 조사
5. GitHub 문서화

이를 통해 수업 내용과 프로젝트 진행 상황을 함께 정리하며 학습 내용을 체계적으로 관리하였다.

---

## 학습 소감

이번 자기주도학습에서는 기말고사 범위를 중심으로 강의 내용을 복습하였으며, 동시에 캡스톤디자인 프로젝트 개발에도 참여하였다.

수업을 통해 소프트웨어 개발 프로세스와 최신 AI 기술 동향을 학습할 수 있었으며, 프로젝트를 통해 팀 협업과 개발 과정의 중요성을 경험할 수 있었다.

앞으로는 프로젝트 완성도를 높이고 사용자 접근성을 더욱 향상시키기 위한 기능 개선을 진행할 계획이다.
