## 1. AI Agent와 MCP 개요

### AI 에이전트란?
- **에이전트(Agent)**: 환경을 지각(Perceive)하고, 그에 따라 행동(Act)하는 모든 것
- **AI 에이전트**: AI 기술을 활용해 환경을 지각하고, 합리적인 판단을 통해 목표를 달성하는 시스템

| 구분 | 인간 | AI 에이전트 |
|------|------|------------|
| 지각 | 오감 (시각, 청각, 후각, 미각, 촉각) | 센서 (카메라, 마이크, 온도 센서 등) |
| 행동 | 근육, 언어, 표정 등 | 액추에이터 (모터, 디스플레이, 스피커 등) |
| 목표 | 생존, 행복, 학습, 문제 해결 등 | 주어진 목표 달성 (최단 경로 탐색, 최적 추천 등) |

### LLM만으로는 부족한 이유
- LLM은 학습된 데이터에 "갇혀" 있음
- 텍스트 생성은 가능하지만, 이메일 전송·파일 수정·코드 실행 같은 **실제 행동은 불가**
- 해결책: **외부 도구(Tools)와 연결** → AI 에이전트로 확장

## 2. MCP (Model Context Protocol)

### 개념
- AI 모델이 외부 데이터 소스나 도구와 **안전하고 표준화된 방식**으로 통신하는 오픈소스 프로토콜
- Anthropic(Claude 개발사) 주도 개발
- **"AI 생태계의 USB-C 포트"** — 연결만 하면 AI가 알아서 도구를 조작

### 핵심 특징
- **표준화**: MCP 서버를 한 번만 구축하면 MCP 지원 AI 에이전트 어디에서든 연결 가능
- **보안**: 사용자가 권한을 통제하며 안전하게 데이터 교환
- **확장성**: 로컬 파일, 사내 DB, 외부 API 등 무한히 확장 가능

### MCP 구성 요소 (3가지)

| 구성 요소 | 역할 | 예시 |
|-----------|------|------|
| MCP 호스트 (Host) | AI 에이전트 프로그램이 실행되는 환경 | Claude Desktop, Cursor IDE, Manus AI |
| MCP 클라이언트 (Client) | 호스트 내부에서 서버와 통신 담당 | client.py |
| MCP 서버 (Server) | 외부 도구/데이터 소스를 감싸고 실행 결과 반환 | Slack, Gmail, Notion MCP 서버 |

### 과거 vs 현재 비교
- **과거**: 각 도구마다 개별 맞춤형 API 개발 필요 (N:N 구조)
- **현재**: 단 하나의 범용 프로토콜로 모든 도구 통제 (1:N 구조)

## 3. 클로드 커넥터 (Claude Connector)

### 개념
- "대화만 하는 AI"를 **"내 업무 도구를 실제로 다루는 AI"** 로 확장하는 장치
- Notion, Gmail, Google Calendar 등 외부 앱과 직접 연결
- 복잡한 설정 없이 몇 번의 클릭으로 연결되는 **노코드(No-code) 솔루션**
- **OAuth** 기반 인증 (비밀번호 노출 없이 안전하게 권한 부여)

### 커넥터가 필요한 이유
- 여러 앱의 실제 데이터를 바탕으로 더 정확하고 실용적인 답변 제공
- 예: "이 회의 관련 메일 요약해줘" → Gmail 연동 시 실제 메일 내용으로 요약 가능
- **업무 자동화**: 노션 회의록 작성 → Gmail 초안 작성 → Google Calendar 일정 등록을 하나의 흐름으로 처리

### 도구 권한 설정
- **항상 허용**: 읽기 전용 도구 (이메일 검색, 캘린더 조회 등)
- **승인 필요**: 쓰기/삭제 도구 (이메일 발송, 일정 생성/삭제 등)

## 4. 클로드 커넥터 활용 사례

### 사례 1 - Gmail: 학생 문의 메일 답장
1. 최근 5일간 지메일에서 학생 문의 메일 내용 정리
2. 주석(comment)에 대한 답변 초안 자동 작성
3. Gmail 임시보관함에 저장 후 수동으로 "보내기" 클릭

> 현재 Claude 커넥터의 Gmail은 **초안 저장까지만** 지원 (직접 전송 불가)

### 사례 2 - Google Drive: 메일 첨부파일 드라이브에 저장
- 오늘 수신된 첨부파일 있는 메일 검색
- 구글 드라이브에 `[날짜] Gmail 첨부파일` 폴더 자동 생성
- 단, **첨부파일 바이너리 직접 추출은 미지원** (본문 텍스트만 반환)

### 사례 3 - Google Drive: 채팅 결과 저장
- Claude 대화 내용을 `\claude\connector` 폴더에 Google Docs 형식으로 저장

### 사례 4 - Notion: 질의 결과 노션에 저장
- Claude에게 질문한 내용을 Notion 페이지로 자동 생성
- 예: `[2026 클로드 추가된 기능]` 페이지 생성 후 저장

### 사례 5 - Google Calendar + Gmail 연동
- Gmail에서 롯데카드 청구서 이메일 검색
- 청구 금액과 납부 마감일 추출
- Google Calendar에 `롯데카드 납부: [금액]원` 형식으로 일정 자동 등록

### 사례 6 - 카카오톡(PlayMCP) 연결
1. `https://playmcp.kakao.com` 접속 후 카카오 계정 로그인
2. '카카오톡 나와의 채팅방' MCP를 도구함에 추가
3. Claude 커넥터에서 PlayMCP 검색 후 연결 (인증 3~4분 소요)
4. Claude에서 카톡 나챗방으로 메시지 발송 가능

## 5. Google Drive 다양한 활용법

### 파일 탐색/검색
- 최근 수정 파일 목록 조회, 키워드 검색, 날짜별 파일 탐색

### 문서 읽기/분석
- Google Docs 링크 내용 요약, 논문 피드백, 강의계획서 주차별 정리, 학생 보고서 채점

### 커넥터 조합 활용
- 드라이브 강의자료 → Gmail로 학생에게 요약 발송
- 드라이브 문서 → Google Calendar에 마감일 일정 추가
- Notion 페이지 ↔ 드라이브 문서 비교

## 6. Claude in Chrome (유료 기능)

### 설치 방법
1. Chrome 웹 스토어에서 "Claude" 검색 후 설치
2. 퍼즐 조각 아이콘 클릭 → Claude 압정 아이콘으로 툴바에 고정
3. Claude 계정으로 로그인 및 권한 허용

### 주요 기능
- 브라우저 사이드 패널에서 Claude와 실시간 대화
- 현재 보고 있는 웹페이지 내용 자동 분석 및 요약
- 웹사이트 탐색, 버튼 클릭, 폼 작성 자동화
- **워크플로우 녹화**: 내 작업 방식을 가르쳐 반복 작업 자동화
- Slack, Gmail, Google Calendar, GitHub 등과 기본 통합
- Claude Code와 통합하여 코드 작성 후 브라우저에서 바로 테스트

### 활용 예시
- pandas 공식 문서 접속 → 주요 함수 정리
- 파이썬 통계 학습 사이트 검색 후 접속 → 내용 정리
- 정리된 내용으로 Gamma에서 PPT 자동 생성

> 금융 사이트(네이버 증권 등)는 **민감 카테고리(sensitive site)** 로 분류되어 접근 불가

## 7. Gemini에서 Google Workspace 연결

- `gemini.google.com/apps` 접속
- Google Workspace 연동: Gmail, Google Calendar, Google Docs, Google Drive, Google Keep, Google Tasks
- `@gmail`, `@Google Calendar` 등 멘션으로 특정 앱 직접 호출 가능
- 질의 결과를 구글 드라이브에 적당한 폴더를 만들어 저장 가능
