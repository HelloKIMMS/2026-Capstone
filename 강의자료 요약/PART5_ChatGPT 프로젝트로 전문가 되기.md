# PART 5. ChatGPT 프로젝트로 전문가 되기

## 11. ChatGPT 프로젝트 탐구

### 프로젝트란?
- 하나의 명확한 목표를 중심으로 **작업 + 자료 + 지침**을 체계적으로 모아 관리하는 공간
- 예시: 보고서 작성, 팀 과제 준비, 취미 생활 계획
- 학업 / 업무 / 개인 취미 등 다양한 분야에서 활용 가능

### ChatGPT 프로젝트 활용 분야

| 분야 | 설명 |
|------|------|
| 아이디어 발전 | 브레인스토밍 파트너로 새로운 관점 제시 |
| 콘텐츠 제작 | 블로그, 시, 소설 등 글쓰기 스타일 제안 및 문장 개선 |
| 학습 및 연구 | 방대한 지식 기반의 명확한 답변으로 학습 효율 향상 |
| 문제 해결 | 단계별 해결 과정 안내로 문제 해결 능력 향상 |

### 프로젝트 만드는 방법
1. 왼쪽 사이드바 → `프로젝트` → `+ 새 프로젝트`
2. 프로젝트 이름 입력 (예: `[보고서 작성] 기후 변화와 청년 세대`)
3. `프로젝트 만들기` 클릭

### 프로젝트 구성 요소

| 구성 요소 | 목적 | 예시 |
|----------|------|------|
| **프로젝트 이름** | 작업 식별, 주제 파악 | "AI 강의용 PPT 슬라이드 제작" |
| **파일 추가** | 참고 자료 제공 | PDF 논문, Word 초안, CSV 데이터 |
| **지침 추가** | 작업 방식·목표 명확화 | 목차 구조, 분량, 응답 방식 지정 |

> ⚠️ 현재 버전에서는 `지침 추가` UI가 제거됨 → 질의(프롬프트) 안에 직접 지침 작성

### 실습 예시: '기후 변화와 청년 세대' 보고서

**질의 프롬프트 구조:**
```
주제: 기후 변화와 청년 세대
서론 / 본론 / 결론 구성
목차 형식: # 제목 / ## 소제목 / ### 내용
분량: A4 5~6페이지
참고문헌 정리 포함
```

**결과물 구조:**
- 1. 서론: 기후 위기의 심각성
- 2. 본론: 기후 변화의 과학적 이해 / 청년의 인식과 참여
- 3. 결론: 실천 행동과 미래 설계
- 참고문헌 5건 정리

### ChatGPT 프로젝트 활용 사례

| 사례 | 대상 | ChatGPT 역할 |
|------|------|-------------|
| 대학생 팀 프로젝트 보고 | 대학생 (조별 과제) | 구조 설계, 문장 다듬기, 요약, 참고문헌 |
| 스타트업 서비스 기획서 | 창업자, 기획자 | 아이디어 정리, 경쟁 분석, 발표 자료 |
| 연구자의 논문 초안 | 대학원생, 연구자 | 논리 흐름 구성, 표현 개선, 문구 수정 |
| 개발자 소프트웨어 설계 문서 | 프로그래머, 엔지니어 | 요구사항 정의, 코드 설명, 문서 자동화 |
| 작가의 시리즈 콘텐츠 집필 | 웹소설 작가 | 세계관 설계, 플롯 확장, 대사 자연스럽게 |

## 12. ChatGPT 프로젝트: 연구 및 전문 분야의 혁신적인 도구

### 연구지원신청서 작성 절차

| 단계 | 주요 내용 | 목적 |
|------|----------|------|
| 1단계 | 연구 주제 선정 및 문제 정의 | 해결하고자 하는 문제 명확화 |
| 2단계 | 선행연구 분석 | 기존 연구와의 차별성 확보 |
| 3단계 | 연구 목적 및 가설 설정 | 연구 방향과 목표 설정 |
| 4단계 | 연구 방법 및 절차 설계 | 수행 계획의 타당성 확보 |
| 5단계 | 연구 일정 및 예산 편성 | 실행 가능성 확보 (Gantt Chart) |
| 6단계 | 기대효과 및 활용 방안 수립 | 연구의 학문적·사회적 가치 제시 |
| 7단계 | 형식 점검 및 제출 | 분량, 형식, 글쓰기 문체 확인 |

### 효과적인 프롬프트(지침) 작성 전략

- **역할 부여**: "당신은 연구 계획 전문가입니다"
- **목표 명시**: 연구 목적과 목표를 구체적으로 제시
- **참고 자료 첨부**: 관련 논문·데이터를 프로젝트에 업로드
- **구체적 지시**: 각 목차별 방향, 포함 내용, 강조 포인트 명시
- **형식 지정**: 글자 크기, 줄 간격, 참고문헌 스타일 등
- **제약 조건**: 분량 제한, 특정 용어 사용 금지 등

### 지침 설계 사례 (LLM 활용 프로그래밍 교육 연구)

```
1. 연구 개요 (500자 내외) - 생성형 AI 활용 동향 및 필요성 포함
2. 연구 목적 (1000자 내외) - 파이썬 정규과목 대상 LLM 활용 효과 분석
3. 연구 방법 (1000자 내외) - 실험군(A반 30명) vs 대조군(B반 30명) 설문 조사
4. 국내외 연구 동향 (500자 내외)
5. 기대효과 및 활용계획 (500자 내외)
6. 향후 계획 (500자 내외)
7. 참고문헌 - 첨부 파일 기반 10개 정리
```

### 작성 원칙 (4가지)
1. **명확성**: 모호한 표현 지양, 직접적·구체적 문장 사용
2. **논리성**: 주장-근거-자료 간 논리적 연결 구조화
3. **일관성**: 전문 용어, 문장 구성, 조사 사용 통일
4. **객관성**: 개인 의견보다 수치·데이터 중심 문장

### ChatGPT 답변의 한계와 보완 방법

| 한계 | 보완 방법 |
|------|----------|
| 연구 의도와 다른 내용 생성 | 내용 검토 및 수정, 후속 질문으로 구체화 |
| 구체적 정보 부족 | 참고 논문의 핵심 내용·연구 방법론 직접 추가 |
| 참고문헌 오류 가능성 | 실제 존재 여부 및 저자·제목·연도 직접 확인 |
| 어색한 문장 | 직접 다듬기 또는 "문장 다듬기" 요청 |

### 후속 질문 예시
- "연구 방법론에서 설문 조사 항목을 구체적으로 3가지 예시로 제시해줘"
- "기존 연구와의 차별성을 더욱 명확하게 설명해줘"
- "예상되는 연구 결과와 교육적 효과를 정량적으로 제시해줘"

### 보고서 최종 완성 단계
1. 전체 통합 검토 요청 → 일관성 확보
2. 포맷팅 및 레이아웃 조정 (학술 양식에 맞게)
3. 그림·표 추가 (필요시)
4. 참고문헌 형식 통일
5. 맞춤법·문법·내용 정확성 최종 점검

## 학술적 윤리와 ChatGPT 활용

- **투명성**: ChatGPT 도움을 받았다는 사실 필요시 명시
- **사실 확인**: ChatGPT가 제공한 정보의 정확성 항상 검증
- **표절 방지**: 최종 문서가 기존 연구와 지나치게 유사하지 않은지 확인
- **개인 기여**: 독창적인 생각과 관점을 반드시 추가

## 핵심 정리

- ChatGPT 프로젝트 = **파일 + 지침 + 채팅**을 하나의 목표 아래 체계적으로 관리
- 지침을 상세하게 작성할수록 결과물의 완성도가 높아짐
- 후속 질문을 통해 부족한 부분을 단계적으로 보완하는 것이 핵심 전략
- 최종 결과물은 반드시 사람이 검토·수정·보완해야 함
