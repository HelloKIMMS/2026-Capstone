## Section 1. claude.ai 개요

### Claude AI란?

Anthropic에서 개발한 생성형 AI

- **설립**: 2021년, ChatGPT를 만든 OpenAI 전 부사장 다리오 아모데이(Dario Amodei) 설립
- **이름 유래**: 정보 이론의 아버지 Claude Shannon에서 영감
- **핵심 철학**: "안전하고 정확한 AI" — AI 위험성 인식, 윤리적·신뢰 가능한 방향 지향

### Claude AI 주요 특징

| 특징 | 설명 |
|------|------|
| 윤리적 AI 원칙 | 안전하고 책임 있는 방식으로 응답 |
| Artifacts | 대화 중 코드·문서·웹사이트를 실시간 생성 및 미리보기 |
| 200K 토큰 컨텍스트 | 약 15만 단어(소설 한 권 분량) 한 번에 처리 |
| 환각(Hallucination) 최소화 | 모르는 것은 모른다고 솔직하게 답변 |
| Extended Thinking | 복잡한 문제를 단계별로 사고하는 심층 추론 기능 |

### Claude 모델 비교

| 모델 | 문학적 의미 | 특징 | 적합한 작업 |
|------|-----------|------|------------|
| Opus 4.6 | 대작 | 최고 성능, 추론 능력 매우 높음, 응답 느림 | 연구·논문·고급 분석 |
| Sonnet 4.6 | 정형시 | 성능·속도 균형, 범용 | 교육·실무·개발 |
| Haiku 4.5 | 짧은 시 | 빠른 응답, 저비용, 경량 | 챗봇·FAQ·실시간 처리 |

> **선택 기준**: 복잡·정밀 → Opus / 균형 → Sonnet / 간결·속도 → Haiku

### 요금제 (2026.3 기준)

| 플랜 | 가격 | 특징 |
|------|------|------|
| Free | 무료 | 일일 사용량 제한, Sonnet·Haiku 접근 |
| Pro | $19/월(연간) | 더 높은 사용 한도, 전체 모델, Claude Code 포함 |
| Max | $110~/월 | Pro 대비 최대 20배 사용량, 우선 접근 |

## Section 2. claude.ai 기본 활용

### 기본 인터페이스

- **왼쪽 메뉴**: 새 채팅, 프로젝트, 아티팩트, 로그인 계정
- **가운데 대화창**: 텍스트 입력, `+` 버튼으로 파일 업로드·Google Drive·GitHub 연결, 모델 선택
- **확장 사고**: 응답 전에 내부에서 충분히 생각할 공간을 부여하는 메커니즘

### 설정 (개인맞춤)

- 업무 유형, 이름 설정
- Claude가 응답에서 고려할 개인 맞춤 설정 입력 (역할, 전문 분야, 사용 목적, 응답 스타일)

### 프로젝트 기능

관련된 대화들을 하나의 작업 공간으로 묶어서 관리 (무료: 최대 5개)

| 핵심 구성 요소 | 설명 |
|--------------|------|
| 지속적 메모리 (Persistent Context) | 프로젝트 내 모든 대화에서 공유되는 System Prompt 설정 가능 |
| 파일 업로드 및 공유 | PDF·코드·문서를 프로젝트 레벨에서 업로드하면 모든 대화에서 참조 |
| 대화 분류 및 정리 | 주제별 대화 구분, 이전 대화 재참조 용이 |

**프로젝트 지침**: 특정 프로젝트의 맥락·요구사항 정의, 해당 프로젝트 내 채팅에만 적용

### 아티팩트 (Artifacts)

Claude가 대화창 옆 별도 패널에 독립적으로 렌더링하는 결과물

| 타입 | 확장자 | 용도 |
|------|--------|------|
| Markdown | .md | 보고서, 문서, 강의 노트 |
| HTML | .html | 웹 페이지, 인터랙티브 UI |
| React | .jsx | 동적 컴포넌트, 대시보드 |
| SVG | .svg | 다이어그램, 일러스트 |
| Mermaid | .mermaid | 플로우차트, ER 다이어그램 |
| PDF | .pdf | 인쇄용 문서 |

**핵심 특징**:
- **렌더링 패널 분리**: 코드 설명과 결과를 동시에 확인
- **반복 수정(Iterative Editing)**: 후속 요청으로 점진적 개선
- **다운로드 및 복사**: 결과물 바로 활용 가능

## Section 3. 스킬(Skill) 개요

### 스킬이란?

> 반복 가능한 작업 또는 워크플로를 위한 **구조화된 지침을 미리 등록**해 자동으로 적용하는 기능

특정 업무의 **표준 운영 절차(SOP)**를 미리 주입해두는 방법

### 스킬의 장점

- 좋은 프롬프트의 반복 작성 불필요 → 시간 절약, 토큰 비용 절감
- 일관된 출력 품질 유지 → 표준화된 결과 생성

### 스킬 작동 원리

1. 대화 시작 시: 스킬의 메타데이터(name, description)만 먼저 로드
2. 관련 요청이 들어오면: 전체 내용을 불러와 실행 (점진적 로딩)
3. 자연어로 워크플로 및 지침 정의 → 코딩 없이도 스킬 생성 가능

### SKILL.md 구조 (핵심 파일)

```yaml
---
name: skill-name          # 스킬 식별자 (항상 메모리 상주)
description: 설명 + 트리거 조건  # 자동 로드 판단 기준
---
# 본문 (트리거 시 로드)
실제 작업 절차, 규칙, 템플릿 (500줄 이하 권장)
```

### 스킬 폴더 구조

```
~/.claude/skills/
└── skill-name/
    ├── SKILL.md          # 핵심 파일 (필수)
    ├── references/       # 상세 참조 문서 (선택)
    ├── scripts/          # 자동화 스크립트, eval (선택)
    └── assets/           # 정적 파일, 템플릿 (선택)
```

### 주요 샘플 스킬 목록

| 스킬 이름 | 설명 |
|----------|------|
| skill-creator | 새로운 스킬 생성 및 기존 스킬 개선 |
| canvas-design | PNG·PDF 등 시각 디자인 결과물 생성 |
| web-artifacts-builder | HTML 기반 복잡한 웹 결과물 생성 |
| algorithmic-art | p5.js 기반 생성형 아트 제작 |
| mcp-builder | MCP 서버 구축 지원 |
| doc-coauthoring | 구조화된 문서 공동 작성 지원 |

## Section 4. 스킬 활용

### 스킬 생성 절차

1. **반복 작업 선정** — 반복성·규칙성·일관성이 중요한 작업
2. **프롬프트 작성** — 스킬 목적 기술 후 프롬프트 정제 요청
3. **Claude의 질의에 응답** — 객관식 질의로 스킬 요건 확정
4. **스킬 생성 대기** — 작업 과정 표시됨
5. **생성된 스킬 확인** — 트리거 키워드, 규칙·예시·금지사항 확인
6. **수정 요청** (필요 시)
7. **테스트** — 자연스러운 문장으로 호출해 결과 확인
8. **반복 개선**

### 스킬 활용 사례: 주식 추천 스킬

- 웹 검색으로 최신 거시경제 지표 수집
- 유망 섹터 2~3개 선정
- 단기(1-3개월) / 중기(6-12개월) / 장기(1년 이상)별 ETF·주식 각 5개 추천
- 트리거: "주식 추천", "ETF 추천", "시황 분석" 등

### "사용자 지정" 메뉴 구성

- **스킬**: 반복 작업 구조화 지침 묶음 (어려운 프롬프트 설계 자동화)
- **커넥터**: Claude가 외부 서비스·데이터 저장소에 접근하는 "데이터 통로"
