# PART 02. ChatGPT: 대화 질문 설계 기초 다지기

## 4. 대화 질문 설계의 세계

### 프롬프트 엔지니어링이란?

- **정의**: 생성형 AI와의 대화에서 원하는 결과를 얻기 위해 질문을 설계·최적화하는 과정
- **목표**: AI의 능력을 최대한 활용하고 사용자의 의도를 정확하게 전달
- **별칭**: 대화 질문 설계 / 대화 질문 최적화

### 프롬프트 엔지니어링이 중요한 이유

- 질문 방식에 따라 답변의 **정확도와 효율성**이 달라짐
- 질문 구조를 체계화하고 핵심 키워드를 활용해야 AI가 의도를 정확히 파악
- AI의 답변에 피드백을 제공 → 성능 향상 및 협력 관계 구축

## 단계별로 구체적으로 질문하기

### "Let's think step by step" 기법

- 질문 끝에 **'단계별로 생각해서(Let's think step by step)'** 추가
- 효과: AI가 각 단계를 명확히 구분해서 더 구체적이고 체계적인 답변 생성

#### 예시: 서울 여행 계획

```
대중 교통을 이용한 서울 여행 계획, 하루 일정 짜줘
- 다음 단계별로 생각해서(Let's think step by step)
* 출발과 도착 지역: 여의도
* 여행 목적: 서울의 현대 문화와 쇼핑, 맛집 방문
* 여행 시간: 아침 9시 출발, 저녁 8시 귀가
* 이동 대중 교통: 버스 또는 지하철
* 관광 명소와 점심, 저녁 식사 추천을 포함한 세부 일정
```

**추가 전 vs 추가 후 비교**
- 추가 전: 간단한 요약 수준의 일정
- 추가 후: 단계별 세부 일정 (여행 목적/교통/세부 일정/귀가) 로 구조적 답변

#### 복잡한 문제 해결 예시 (환경 문제)

```
"환경 문제를 해결하기 위한 방법은 무엇인가요?"를 단계별로 짜줘
- 1단계: 문제 정의
- 2단계: 원인 분석
- 3단계: 해결책 제안
```

## 5. 대화 질문의 구성 요소 탐구

### 목적·맥락·역할 이해하기

| 요소 | 설명 | 예시 |
|------|------|------|
| **목적 (Objective)** | 질문을 통해 무엇을 얻고자 하는지 명확히 | "한국 역사에 대해 알려줘" → "조선시대 임진왜란의 배경과 결과를 요약해줘" |
| **맥락 (Context)** | 질문의 배경과 상황 제공 | "이 책에 대해 설명해줘" → "최근 베스트셀러인 '세상의 마지막 기차역'의 줄거리와 등장인물을 소개해줘" |
| **역할 (Role/Persona)** | AI가 수행할 기능 정의 | "네가 역사 선생님이라고 생각하고 임진왜란에 대해 설명해줘" |

### 청중과 예시

- **청중 (Audience)**: 질문 대상의 수준에 맞게 프롬프트 설계
  - 초등학생 → 쉬운 비유와 간단한 설명
  - 대학생 → 비판적 사고와 심층 분석
- **예시 (Examples)**: 원하는 결과의 형태·내용·스타일을 AI에게 명확히 보여줌
  - "한국의 유명한 시인에 대해 알려줘" → "윤동주의 '서시'처럼 감성적인 시를 쓰는 시인 3명을 소개해줘"

### 대화 질문 설계의 10가지 구성 요소

| 유형 (Type) | 설명 | 예시 |
|-------------|------|------|
| 목적 (Objective) | 글의 목적을 명확히 설정 | "전기차 구매 시 고려해야 할 사항을 알려줘" |
| 상황 (Context) | 배경 정보, 상황, 추가 자료 설명 | "이 상황의 배경, 목표, 고려해야 할 점, 제약 사항을 포함해 설명해줘" |
| 역할 (Role, Persona) | ChatGPT의 역할 또는 관점 지정 | "너는 대학 교수야. 마케팅 전문가라 생각하고 답해줘" |
| 청중 (Audience) | 대상이 되는 목표 독자를 구체적으로 명시 | "초등학교 5학년 수준, 대학 신입생, 경영진 대상" |
| 예시 (Examples) | 원하는 형식이나 스타일의 예시 제공 | "'긴 글 → 핵심 요약' 형태로 만들어줘" |
| 형식 (Format) | 결과물의 구조나 형식 지정 | "문단으로 정리해줘, 표로 정리해줘" |
| 키워드 (Keywords) | 반드시 포함해야 할 단어나 개념 지정 | "반복적 접근, 신속한 엔지니어링 포함해줘" |
| 제한 (Limitations) | 답변의 길이, 단어 수, 문장 수 등 제한 | "200단어 이내, 3문장으로 작성, 예시 5개 포함" |
| 어조 (Tone) | 글의 분위기와 스타일 지정 | "친절하게 설명해줘, 전문가의 시각에서 작성해줘" |
| 부정 (Negation) | 피해야 할 내용 명시 | "기술 용어를 남발하지 말고, 너무 어렵게 설명하지 마" |

### 주요 문자 기호 활용

형식을 명확히 하고 AI와의 소통을 효과적으로 만드는 기호들:

| 기호 | 용도 | 질문 예시 |
|------|------|----------|
| `-` 하이픈 | 목록의 각 항목 표시 | `- 주제 소개 및 배경 설명` |
| `""` 따옴표 | 특정 단어·문구 강조 | `"인공지능"의 정의를 설명해주세요` |
| `:` 콜론 | 목록이나 설명 시작 | `다음 형식으로 답변해주세요:` |
| `*` 별표 | 목록 표시 또는 강조 | `*빅 데이터*의 장단점을 알려주세요` |
| `[]` 대괄호 | 추가 정보·선택 사항 표시 | `[사용자 입력]을 받아서 환영 메시지를 출력하는 프로그램` |
| `{}` 중괄호 | 특정 조건 명시 | `{제목}: "인공지능의 현재와 미래"` |
| ` ``` ` 백틱3개 | 코드 블록 표시 | ` ```python def add(a,b): return a+b ``` ` |
| `#` 해시 | 마크다운 제목·섹션 구분 | `# 서론 ## 본론 ### 결론` |

## 6. 효율적인 대화 질문: 퓨샷 프롬프팅

### 퓨샷 러닝(Few-shot Learning)이란?

- AI 모델이 **제한된 수의 예시**만으로 새로운 개념이나 작업을 학습하는 기술
- 기존 머신러닝: 방대한 데이터 필요 → 퓨샷 러닝: 단 몇 개의 예시로 학습 가능
- 활용 상황: 데이터 부족, 빠른 적응 필요, 개인화 서비스

### 퓨샷 프롬프팅 유형 비교

| 유형 | 예시 수 | 설명 | 특징 |
|------|---------|------|------|
| **Zero-shot** | 0개 | 예시 없이 바로 결과 요청 | 빠르지만 정확도 낮을 수 있음 |
| **One-shot** | 1개 | 예시 1개 제공 후 결과 요청 | 제로샷보다 정확도 향상 |
| **Two-shot** | 2개 | 예시 2개 제공 후 결과 요청 | 패턴 학습에 효과적 |
| **Few-shot** | 3개+ | 여러 예시를 제공해 결과 유도 | 복잡한 패턴·규칙 학습에 적합 |

### 유형별 질문 사례

#### Zero-shot (예시 없이 바로 질문)
```
다음 문장의 감정을 분류해 주세요: '오늘 옷을 사서 돈을 많이 지출했어요.'
```

#### One-shot (예시 1개 제공)
```
다음은 예시입니다.
- [긍정]: '선물을 받아서 기분이 좋아요.'
- [부정]: '숙제를 못 해서 속상해요.'

다음 문장의 감정을 긍정 또는 부정으로 분류해 주세요: '오늘 옷을 사서 돈을 많이 지출했어요.'
```

#### Two-shot (예시 2개 제공)
```
Q: "머신러닝이란?" A: "데이터 학습 기술입니다."
Q: "딥러닝이란?" A: "신경망을 이용한 학습 기법입니다."
Q: "강화학습이란?" A:
```

### 퓨샷 활용 실전 예시 (감정 분류)

```
[긍정 예시] "정말 감동적이었어!" → 긍정
[부정 예시] "너무 지루했어." → 부정
→ 새로운 문장: "오늘 식당이 너무 붐볐지만 음식은 맛있었어." → ?
```

## 핵심 정리

- **프롬프트 엔지니어링** = 원하는 결과를 얻기 위한 질문 설계 기술
- **"Let's think step by step"** 추가 → 단계적·구조적 답변 유도
- 좋은 질문의 10가지 요소: **목적·상황·역할·청중·예시·형식·키워드·제한·어조·부정**
- 문자 기호(`-`, `""`, `#`, ` ``` ` 등) 활용으로 가독성과 AI 이해도 향상
- **퓨샷 프롬프팅**: 예시를 많이 줄수록 더 정확하고 원하는 형태의 답변 획득 가능
